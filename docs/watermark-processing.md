# v0.2.0 水印处理

## 使用步骤

1. 进入左侧“水印处理”，点击“打开本地视频”。已完成的下载任务也提供橡皮图标入口。
2. 在原始帧上拖动框选水印，最多添加 8 个区域。水印周围留少量余量，避免融合边缘保留文字残影。
3. 选择背景覆盖或局部模糊。点击区域列表可以修改某处的处理方式及像素坐标。
4. 背景覆盖默认使用邻近区域；需要调整时，选中该区域并点击“在画面中选取参考背景”，再点击干净背景的中心。蓝框显示参考位置，不能与自身水印重叠。
5. 若水印在边缘且可以舍弃边缘画面，可切换“裁剪保留画面”，框出最终要留下的内容。所有覆盖／模糊先执行，裁剪最后执行。
6. 拖动取帧时间，点击“读取此帧”查看另一时刻。处理区域固定在画面坐标中，原始帧用来框选，不显示处理结果。
7. 点击“生成 5 秒预览”，从所选时间开始处理最多 5 秒，并在页面下方播放真实处理片段。
8. 核对运动时的效果后，点击“另存完整处理副本”。更改框选、方式、裁剪或预览时间后，必须重新生成预览。

处理任务支持进度和取消。完整副本导出后可直接定位文件；同名现有文件会被拒绝覆盖，原始视频始终保留。

## 方法与效果边界

- **背景覆盖**：复制所选邻近背景，使用透明边缘做融合。适合角落、侧栏、变化较少的背景。它不是 AI 修复，复杂背景可能出现拼接痕迹；参考区域中若有人物、字幕或其他标识，也会被复制到覆盖位置。
- **局部模糊**：只模糊框选区域，不恢复其下的画面。适合接受模糊块的场景。
- **裁剪**：保留框内画面，丢弃外围内容，输出尺寸和宽高比可能变化。

作者标识和哔哩哔哩标识均按画面中的普通固定区域处理，无自动标识检测、文字识别或移动跟踪。遮挡人物、复杂纹理和移动水印的效果需逐片检查；不能保证还原被遮住的真实细节。

## 编码与支持范围

输出为 H.264、CRF 18、yuv420p 的 MP4。视频经过重新编码，不等同于原画质下载或无损保存；下载功能自身仍使用无重编码合并。

AAC／MP3 音轨直接复制；其他音轨转 AAC 192 kbps。保留可处理的全部音频轨道，字幕、附件、章节等不随副本导出。5 秒预览与完整导出使用相同区域和处理规则，编码速度预设分别为 fast／medium。

支持常见 MP4、MKV、MOV、WebM、M4V、AVI 的本地 SDR 文件。HDR／杜比及非方形像素源暂拒绝处理，以免输出错误颜色或坐标。旋转方向按显示后的画面换算，并通过带旋转元数据的样本测试。

## 实现与验证

React 的拖动坐标保存为相对于视频画面的 0～1 数值。Python 按实际显示尺寸换算成对齐后的像素坐标，构建固定的 FFmpeg filtergraph：crop／boxblur／overlay／geq，最后裁剪并编码。参数不拼接到 shell 执行。

帧图及片段通过本机 `vido-media` 协议提供。协议只识别应用登记的随机令牌，不接受任意本地路径，支持视频播放器使用的 Range 请求。主进程再次校验输入、源文件大小与修改时间、预览设置及输出位置。

预览缓存在应用 `userData/watermark-cache`，下次启动清理。该目录只用于临时文件；正式导出副本保存在用户选择的位置。

已用模拟侧栏角标视频验证白色角标区域发生预期替换、两个区域的组合处理、手选参考位置、边缘区域、裁剪尺寸、音轨、预览时长、旋转方向、源文件哈希不变及禁止覆盖。Electron 桌面测试覆盖框选、播放预览、媒体 Range、完整副本导出、修改后预览失效和取消。

此版本未对用户截图对应的完整视频做效果验收，因为本次提供的是截图。功能测试使用可控的模拟视频；真实视频需要在客户端预览确认效果。
